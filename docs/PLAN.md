## Зачем это приложение

Портфолио Android-разработчика уже закрывает: офлайн-first и синхронизацию (Expenses, DevLog, SkyCast), KMP (DevLog),
нативное ядро на Rust (Solmu), виджеты и WorkManager. Galleria — **красивое и несложное** приложение, которое показывает то,
чего в портфолио ещё нет:

| Тема собеседования | Где в Galleria |
|---|---|
| **Paging 3** — бесконечная лента, состояния загрузки/ошибки, retry | лента и поиск |
| **Загрузка картинок** (Coil 3): кэш, плейсхолдеры, crossfade, размеры | все экраны |
| **Shared element transitions** (Compose 1.7+) | плитка → экран картины |
| **Адаптивная вёрстка** (телефон / планшет / складной: список + детали рядом) | Material 3 Adaptive |
| **Жесты**: зум и сдвиг картинки (`transformable`), двойной тап | полноэкранный просмотр |
| Цвет из данных: фон экрана по преобладающему цвету картины | экран картины |
| Поиск с debounce, отмена устаревших запросов (`flatMapLatest`) | поиск |
| Room как локальное «избранное», работает без сети | избранное |

## Источник данных — API Art Institute of Chicago

- База: `https://api.artic.edu/api/v1/`, **без ключа**. Музей просит заголовок `AIC-User-Agent: Galleria/<версия> (контакт)` — добавляет OkHttp.
- Лента и поиск: `GET artworks/search?q=…&query[term][is_public_domain]=true&page=&limit=&fields=…`
  - фильтр `is_public_domain=true` → у всех результатов есть `image_id` (проверено: 0 из 50 без картинки), ~62 тыс. работ;
  - `q` ранжирует (Моне первыми), но не фильтрует — `total` остаётся общим;
  - **потолок: 1000 результатов на выдачу** (страница × размер ≤ 1000, дальше ошибка «Invalid number of results») → лента
    заканчивается на ~990 работах; в UI — честное «Это всё по запросу, уточните поиск».
- Карточка: `GET artworks/{id}?fields=…` (описание `description` — HTML).
- Картинки — IIIF: `https://www.artic.edu/iiif/2/{image_id}/full/{ширина},/0/default.jpg`; рекомендованная ширина 843, превью — 400.
- Полезные поля: `thumbnail.lqip` (крошечное размытое превью base64 — **заглушка до загрузки**), `thumbnail.width/height`
  (**пропорции плитки заранее**, без прыжков), `color {h,s,l}` (**преобладающий цвет** — фон экрана картины),
  `artist_title`, `date_display`, `medium_display`, `dimensions`, `place_of_origin`, `style_title`, `department_title`, `credit_line`.

## Экраны и фичи

### MVP (версия 1.0)

1. **Лента «Галерея»**
   - [ ] Плитка разной высоты (`LazyVerticalStaggeredGrid`): 2 колонки на телефоне, 3–4 на планшете (по ширине окна).
   - [ ] Плитка: картинка с пропорциями из API, пока грузится — размытое `lqip`, затем плавное появление; подпись: название (с засечками) и автор.
   - [ ] Подборки-чипсы над лентой: «Все», «Импрессионизм», «Япония», «Портреты», «Пейзажи», «Натюрморт», «Античность»
         (каждая — заранее заданный запрос `q`). Выбранная подборка переживает поворот экрана.
   - [ ] Paging 3: подгрузка при прокрутке, индикатор внизу; ошибка сети — плашка «Нет связи · Повторить»; ошибка первой
         загрузки — экран с «Повторить»; конец ленты (потолок 1000) — подпись.
   - [ ] Pull-to-refresh.
2. **Поиск**
   - [ ] Поле поиска в верхней панели; запрос уходит через 400 мс после последней буквы (debounce), устаревший запрос
         отменяется (`flatMapLatest`); пустой запрос — возврат к подборке.
   - [ ] Пустой результат — «Ничего не нашлось» с подсказкой.
3. **Экран картины**
   - [ ] Картинка большого размера с **shared element** из ленты (ключ `image-{id}`) — летит из плитки на место.
   - [ ] Фон — мягкий градиент из `dominantColor` (с учётом светлой/тёмной темы — проверка контраста текста).
   - [ ] Название, автор полностью, дата; «факты» строками: техника, размеры, место, стиль, отдел музея, источник.
   - [ ] Описание музея (HTML → текст); пока грузятся подробности — скелет строк.
   - [ ] Кнопка ♥ (избранное) с анимацией; «Поделиться» (ссылка `https://www.artic.edu/artworks/{id}`).
   - [ ] Тап по картинке — полноэкранный просмотр: зум щипком и двойным тапом, сдвиг, закрытие свайпом вниз.
4. **Избранное**
   - [ ] Вкладка с той же плиткой; хранится в Room целиком (работает без сети); свайп/кнопка — убрать, с «Отменить».
   - [ ] Пустое состояние с призывом «Отметьте ♥ картины, которые понравились».
5. **Общее**
   - [ ] Нижняя навигация «Галерея · Избранное» (на планшете — `NavigationRail`).
   - [ ] Тема «музей»: тёплая бумага + бордовый, тёмная тема; заголовки с засечками (уже в `ui/theme`).
   - [ ] Заставка (splash), адаптивный значок (+ монохромный для Android 13+).
   - [ ] Edge-to-edge, корректные отступы (урок SkyCast: не применять отступ статус-бара дважды).
   - [ ] Локализация ru + en.
   - [ ] Доступность: `contentDescription` из `thumbnail.alt_text`, крупный шрифт не ломает плитку.

## Архитектура

Один модуль `app`, слои — пакетами (многомодульность уже показана в SkyCast; здесь акцент на UI).

```
ui (Compose)            ViewModel (StateFlow / PagingData)      data                              сеть / БД
feed/FeedScreen   ──►   FeedViewModel  ── query ─► flatMapLatest ─► ArtworkRepository.artworks(q) ─► Pager ─► ArtworkPagingSource ─► ArticApi (Retrofit)
detail/Detail…    ──►   DetailViewModel ─────────────────────────► details(id), isFavorite(id) ───► ArticApi / FavoriteDao (Room)
favorites/…       ──►   FavoritesViewModel ──────────────────────► favorites() ─────────────────► FavoriteDao
                         Hilt собирает всё (di/AppModule); Coil — на общем OkHttp (GalleriaApp)
```

- **UDF**: экран = `Screen(state, callbacks)`; ViewModel отдаёт `StateFlow<UiState>` и `Flow<PagingData<Artwork>>`
  (`cachedIn(viewModelScope)` — лента не перезагружается при повороте).
- **Модель** `Artwork` уже без особенностей API (адреса, пропорции, цвет готовы) — маппер `data/ArtworkMapper.kt`, чистые функции.
- **Навигация**: Navigation Compose с типобезопасными маршрутами (`@Serializable`), `SharedTransitionLayout` вокруг `NavHost`.
- **Ошибки**: `IOException` → «Нет связи», `HttpException` → «Сервер музея недоступен (код)».

## Версия 1.1 — «вау для демонстрации» (план от 2026-10-11, вечер)

Исследование API (проверено curl): поиск принимает JSON `params` (текст `q` + фильтры `bool.filter`):
диапазон по цвету `range color.h / color.s`, `term artist_id`, `term artwork_type_title.keyword`; биография
художника — `/agents/{id}`; автодополнение — `/autocomplete?q=&resources=artworks,agents`; у картинок IIIF-тайлы
256 px с масштабами 1…128 (`info.json`), оригиналы до ~9000 px (`/full/full` запрещён, регионы — можно).

Найденный пользователем баг: при наборе панель обновляется на каждую букву (пауза 400 мс короче, чем между
буквами на телефоне) + большой кружок pull-to-refresh выскакивает при каждом новом запросе.

Порядок работ:
1. [x] **Поиск**: пауза 650 мс, запрос только с 3 букв, «Найти» на клавиатуре — сразу; вместо кружка —
   тонкая полоска под полем, старые результаты видны (приглушены) до прихода новых; подсказки автодополнения
   (художники и работы) под полем; недавние запросы.
2. [x] **Слой данных**: `SearchQuery` (текст, художник, цвет, тип) → JSON `params` — чистая функция с тестами.
3. [x] **Поиск по цвету**: ряд цветных кружков (красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый,
   «тёмные») — лента картин этого цвета. Красиво на демо.
4. [x] **Экран картины богаче**: параллакс картинки при прокрутке; акцентный цвет экрана из картины (♥, кнопки);
   ряд «Ещё у художника» и ряд «Похожие по цвету» (горизонтальные ленты, переход по ним тоже с shared element);
   нажатие на художника — **экран художника** (годы жизни, биография, все работы плиткой).
5. [x] **Глубокий зум (IIIF deep zoom)**: свой рендер тайлов на Canvas — при приближении догружаются только
   видимые куски оригинала нужного масштаба; можно дойти до мазков кисти (8808 px у «Водяных лилий»).
6. [x] **«Картина дня»**: большая карточка-герой вверху ленты + **виджет Glance** на рабочий стол (WorkManager раз в сутки).
7. [x] **Режим «Погружение»**: полноэкранный вертикальный пейджер картин с медленным наездом камеры (Ken Burns),
   размытым фоном из картины и автопрокруткой — «музей в кармане».
8. [ ] Полировка: тесты на всё новое, скриншоты/GIF в README, CHANGELOG, версия 1.1.0, CI зелёный.
